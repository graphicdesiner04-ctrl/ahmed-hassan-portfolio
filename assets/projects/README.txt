حط صور مشاريعك هنا
========================

الاسم المقترح: project-1.jpg, project-2.jpg, ...
أو باسم المشروع: zahra-jewels.jpg, ramadan-nights.jpg, ...

بعد ما تحط الصورة هنا، روح لـ projects.js وعدّل حقل image:
  image: 'assets/projects/zahra-jewels.jpg',

الأحجام المناسبة:
  - كارد عادي (wide: false) → 800×600 px (4:3)
  - كارد واسع (wide: true)  → 1200×675 px (16:9)
  - صيغة JPG أو WebP للأداء الأفضل
